# ANIMATE

**Status: engineering repository — source import pending, not deployed or validated for sale.**

ANIMATE experiments with browser-based physical interaction using colour tracking, foreground motion and an optional MediaPipe hand landmark adapter. Current colour/foreground methods are not AI object recognition, and the hand-ML mode requires verified separately bundled runtime/model files.

The v0.7 candidate is prepared outside this repository; source must be imported and verified on a separate branch before a merge or CI success can be claimed.

See [Integration and release gates](INTEGRATION_AND_RELEASE_GATES.md) for the current assignment and safety requirements.

No participant files or research ledgers belong in this public repository.

**Do not deploy or recruit participants until model rights, privacy terms, automated CI and real-device testing are approved.**
